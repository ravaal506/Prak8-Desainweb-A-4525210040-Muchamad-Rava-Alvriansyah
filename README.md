
# TECHFEST - Form Registrasi Event

## Deskripsi
TECHFEST merupakan sebuah website Form Registrasi Event
yang dibuat menggunakan HTML dan CSS.

Website ini digunakan sebagai media pendaftaran peserta
untuk kegiatan seminar teknologi. Tampilan dibuat modern,
minimalis, dan responsif sehingga mudah digunakan melalui
komputer maupun smartphone.

## Fitur Website
1. Form input nama lengkap.
2. Form input alamat email.
3. Form input nomor handphone.
4. Form input asal institusi.
5. Pilihan kategori peserta.
6. Pilihan jenis tiket Reguler dan VIP.
7. Form alasan mengikuti event.
8. Pilihan tanggal pendaftaran.
9. Checkbox persetujuan pendaftaran.
10. Validasi input menggunakan HTML.
11. Tampilan responsif untuk berbagai ukuran layar.

## Teknologi yang Digunakan
- HTML5
- CSS3
- Visual Studio Code
- Live Server

## Struktur Folder

Registrasi-Event/
│
├── index.html
├── style.css
└── README.md

## Cara Menjalankan Project

1. Download atau salin seluruh file project.
2. Buka folder Registrasi-Event menggunakan Visual Studio Code.
3. Pastikan file index.html dan style.css berada dalam
   satu folder.
4. Install extension Live Server jika belum tersedia.
5. Klik kanan pada file index.html.
6. Pilih Open with Live Server.
7. Website Form Registrasi Event akan terbuka di browser.

## Cara Menggunakan Form

1. Buka halaman website.
2. Isi nama lengkap peserta.
3. Masukkan alamat email dan nomor handphone.
4. Isi nama institusi.
5. Pilih kategori peserta.
6. Pilih jenis tiket yang tersedia.
7. Tuliskan alasan mengikuti event.
8. Tentukan tanggal pendaftaran.
9. Centang persetujuan pendaftaran.
10. Klik tombol Daftar Sekarang.

## Tujuan Pembuatan
Project ini dibuat untuk mempelajari dasar-dasar
pengembangan website menggunakan HTML dan CSS,
khususnya dalam pembuatan form, penggunaan input,
validasi data, pengaturan layout, dan desain responsif.

## Catatan
Project ini merupakan contoh pembelajaran front-end.
Data pendaftaran belum tersimpan ke database karena
belum menggunakan backend.
